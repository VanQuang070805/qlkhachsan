# Operations Shell Component Spec

Interaction model: click and keyboard driven.
DOM: workspace shell / sidebar / topbar / main / command palette.
Desktop: 248px sidebar, 1px divider, 28px main padding.
Collapsed/mobile: 72px icon rail; text hidden.
Dark panels use rgba(255,255,255,.08) borders and no heavy shadow.
Active navigation uses raised panel fill and white text.
Hover transition: background and color 160ms ease.
