# Portal Topology

## Admin
Persistent collapsible sidebar -> top utility bar -> route content.
Routes: financial overview, room operations, users/RBAC, dynamic pricing.
Dashboard: filters -> KPI strip (Revenue, ADR, RevPAR, Occupancy, Bookings) -> revenue chart -> booking status -> ledger.

## Staff
Persistent role-limited sidebar -> top utility bar -> room matrix.
Room matrix: command row -> state chips -> filters -> floors -> room cards -> booking slide-over.
Interactions are click and keyboard driven. Search/filter state persists in URL.

## Responsive
Desktop keeps full sidebar. Tablet collapses automatically. Mobile uses 72px icon rail and one-column content.
